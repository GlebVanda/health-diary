# История изменений

Формат: [семантическое версионирование](https://semver.org/lang/ru/). Номер версии хранится в `js/version.js`.

## 1.0.0 — первый выпуск

- Первичная настройка: анкета подготовки (выносливость и сила отдельно, ИМТ, вопросы по здоровью) → цели → расписание.
- Основная цель и дополнительные цели, которые корректируют сценарий; проверки безопасности целей.
- Питание: недельный бюджет с переносом перебора, автоматическая норма, Б/Ж/У.
- Тренировки: генератор плана по правилам, автоматическая адаптация по факту с причиной и отменой.
- Главная с динамикой и сравнением периодов; вес на главной, объёмы и фото тела с сравнением снимков в профиле.
- Импорт истории из Excel, резервная копия вместе с фото, необязательный PIN, тема в стиле уличного мерча.
- Облачная синхронизация через Supabase (вход по почте и паролю, офлайн-режим, фото в хранилище), выпуск через GitHub Actions на GitHub Pages.
- 128 автоматических тестов в браузере, запуск в GitHub Actions.
